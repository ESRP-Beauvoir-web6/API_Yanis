# Consommer une API-rest

Ce projet montre comment mettre en place les différents composants nécessaires pour consommer l'API "Rick et Morty"
Les vues "episodes.php" et "lieux.php" restent à terrminer.

Si vous récupérez ce projet, vous devrez mettre à jour la variable `$projectUrl` dans les fichiers `index.php` et `views/templates/header.php`.
